# 日本語校正

AI が書いた日本語ドキュメントを `japanese-proofreader` サブエージェントで校正する。

**位置づけは「校正」ではなく「AI が書いた文章の品質ゲート」。**
設計書もレビュー記録もガイドも、ほぼ全量が AI の書いた日本語で、しかも**長期間残って
後から読む人の判断材料になる**。読みにくい文章は判断を誤らせる。

> **いつ使うか**: 設計書やガイドを書き終えた区切り、外部に出す文書を作ったとき、
> `update-docs` / `sync-check` で設計書をまとめて更新した後。
> **毎回のコミットごとに回すものではない**（差分レビューの負担に見合わない）。

## Step 1: 対象の決定

$ARGUMENTS にパス（ファイル・ディレクトリ）があればそれを対象にする。

未指定なら**直近の変更**から選ぶ:

1. 未コミットの変更: `git diff --name-only` ＋ `git status --short`
2. 1 が空なら直近コミット: `git diff --name-only HEAD~1 HEAD`

そのうち **`.md` / `.html`** のみを対象にする。次は**対象外**:

| 対象外 | 理由 |
|--------|------|
| ソースコード | 校正の対象は文章。コード内コメントは実装の文脈で読むもの |
| `CHANGELOG.md` / 各文書の改訂履歴 | **過去の記録は書き換えない** |
| 自動生成される設計書（`designDocs` の生成物） | 生成器を直さない限り次の生成で戻る |
| `.claude/rules/` / `harness.config.json` | 規約・設定であって読み物ではない |

対象が0件なら、その旨を報告して終了する。

## Step 2: サブエージェントへ委譲

`japanese-proofreader` を起動する。ファイル数が多い場合は **5〜10 ファイル程度のバッチ**に分けて
並列で起動する（1エージェントに大量に渡すと精読が浅くなる）。

プロンプトには**必ず**次を含める:

- 対象ファイルの**絶対パス一覧**
- 「**全文を精読すること**（パターン検索だけに頼らない）」
- 「**意味・仕様・UI 名は変えない**。疑わしい事実は修正せず要確認として報告する」
- 文書の**読み手**（開発者向けか利用者向けか）。5番目のパターン（内部用語の露出）の判断が変わる

> **モデルは指定しない。** 文章品質が要るため上位モデルが望ましいが、
> **モデル名は将来変わる**ため、ハーネス側では固定しない。
> プロジェクトの CLAUDE.md / constitution.md に方針があればそれに従う。

## Step 3: メインで差分レビュー（必須）

`git diff` で**全修正を目視確認する。機械的にコミットしない。**

**サブエージェントの結果を無条件に信用しない**のはハーネス共通の規律だが、校正では特に効く。
文章の修正は typecheck も lint も通らない — **壊れても検出する仕組みが無い**。
実際に、校正の過程で文法が破綻した / 強調の範囲がずれた実例がある。

| 見るもの | 判断 |
|---------|------|
| **意味が変わっていないか** | 技術的な内容が書き換わっていたら**戻す** |
| **記法が壊れていないか** | 表の列ずれ、コードブロックの開閉、リンク、見出し階層 |
| 修正しすぎていないか | 元の方が自然な箇所は戻す。**差分は小さいほどよい** |
| **要確認事項** | 実装・設定・UI の文字列リソースと突き合わせて**メインが判断する** |

不適切な修正は元に戻すか手直しする。

## Step 4: コミット

- **対象パスを明示してコミットする**（`git commit -- <path...>`。`git add -A` は使わない）
- メッセージは `docs: 日本語校正（〜）` の形で、**直した分類**を箇条書きにする
- **push はユーザーの指示を待つ。** 公開文書は push が公開に直結する

## 新しいパターンを見つけたら

サブエージェントが報告した「7分類に当てはまらない不備」は、**その場では直さずに記録する**
（constitution §8）。区切りで振り分ける:

| 種類 | 行き先 |
|------|--------|
| **プロジェクト固有**の用語・表記の揺れ | プロジェクトの `.claude/rules/` |
| **環境非依存**の日本語パターン | ハーネスへ還元する（`agents/japanese-proofreader.md` の分類表） |
