# マニュアルの文書群ブリーフの案

`add-distribution-site` が置いたマニュアルの枠（`web/manual/`）を、harness-doc で書くときの決め事の**案**。
**このファイルはプロジェクトへ写さない。** ブリーフ（`.claude/rules/doc-brief-manual.md`）は harness-doc が
専用のスクリプトで書く決まりなので、ここの値は `/harness-doc:setup-project`（Step 2C）と
`/harness-doc:plan-doc` に**案として渡す**だけにする。値は利用者に確かめてから「確定」にする。

`{{...}}` は SKILL.md の「差し替える値の一覧」と同じ値で読み替える。

## 文書群（setup-project の Step 2C に渡す案）

| 項目 | 案 | 確かめること |
|---|---|---|
| 名前 | `manual` | — |
| 文書群の名前 | 利用マニュアル | — |
| `paths` | `web/manual/**` | — |
| 読者のプロファイル | engineer（開発者向けのツール）／ beginner（一般の人向けのアプリ） | **アプリの利用者で決まる。必ず聞く** |
| 読者像 | 「このアプリを初めて使う、〇〇をしたい人」の形で 1 文 | 利用者に書いてもらう |

## 文書ごとの決め事（plan-doc で改訂設計書を作るときの案）

`paths` の基点（`web/manual/`）からのパスで書く。

| 文書 | 文書の種類 | ゴール | 受け入れ基準の案 |
|---|---|---|---|
| `index.html` | landing | 自分の目的に合うページへ 1 回のクリックで移る | 目的（初めて使う／インストールと削除／画面の意味を調べる／うまくいかない）から 1 回のクリックで該当ページへ移れる。改訂履歴へ移れる |
| `getting-started.html` | tutorial | 最初の 1 回を、見本のデータでたどり、結果を確かめる | このページだけで最後まで到達できる。各手順に目に見える結果がある。見本のデータは個人のフォルダを使わない |
| `install.html` | howto | 2 種のインストーラーから選んで入れ、更新・アンインストールし、残るものを消す | どちらのインストーラーを選ぶかが分かる。管理者の確認が出る場面（あれば）が分かる。アンインストール後に残るもの（設定とデータ・WebView2 の作業ファイル）の場所と消し方が分かる |
| `faq.html` | reference | 表示されたメッセージや症状から、原因と対処を引く | 症状ごとに、原因・対処・アプリで確かめる場所を引ける（症状の一覧は依頼者と決める） |
| `history.html` | history | いつ・どのページが変わったかを知る | 1 行ずつ、日付・ページ・変えたこと・アプリの版が読める |
| `screens/<画面>.html` | reference | その画面の表示・ボタン・項目の意味を引く | 画面のどの表示・ボタン・項目についても、意味と押したときに起きることを引ける。この画面から開く窓の説明へ移れる。画面名・ボタン名はアプリの表示と一字一句同じ。**F1 の飛び先の表（`HelpTargets.cs`）にある節の id がすべてある** |
| `safety.html`（任意） | explanation | 実行する前に、何が・どこへ消えるか、元に戻せるかを理解する | 消える操作ごとに、行き先（ごみ箱・退避先・完全に消す）と元に戻せるかがまとめの表で分かる。アプリが止める条件が分かる。「安全です」と言い切らない |

## 書く人への申し送り

- **相対リンクだけで書く。** 絶対 URL は配布サイトのトップ（`{{SITE_URL}}`。目次の末尾にある）だけ。外部の画像・CDN・Web フォントを読まない（同梱のヘルプ窓と `file:///` で同じに見えなくなる）
- ページを足したら、`web/assets/js/main.js` の目次と `index.html` のカードにも足す
- 各ページの `<!-- 雛形: ... -->` の印は、本文を書いたら消す（公開前の検査 `check-web.mjs --dist` が、残っていると止める）
- 画面写真は `/harness-wpf:capture-screenshots` で撮り、`web/assets/img/screens/` に置く
- 書き終えたら `node tools/check-web.mjs` を通す（F1 の飛び先の節が消えていないかも見る）
