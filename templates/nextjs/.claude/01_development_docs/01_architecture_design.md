## レイヤー構成（推奨・既定）

```
┌─────────────────────────────────┐
│  Presentation                   │ React Components（page.tsx / feature components）
├─────────────────────────────────┤
│  State                          │ ストア（API キャッシュ + 画面をまたぐ状態）
├─────────────────────────────────┤
│  Service                        │ ビジネスロジック
├─────────────────────────────────┤
│  Repository / Data              │ データアクセスの抽象化
├─────────────────────────────────┤
│  Infrastructure                 │ DB（Prisma）/ 外部 API
└─────────────────────────────────┘
```

**依存の向きは上から下の一方向。** 下位層が上位層を参照してはならない。

- **API Route から直接 DB を操作しない**（必ず Service 層を経由する）
- Server / Client Components を適切に分離する
