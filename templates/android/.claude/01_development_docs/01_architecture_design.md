## レイヤ構成（推奨・既定）

```
{{MODULE_NAME}}/src/main/java/<パッケージ>/
├── ui/        # 画面（Composable）・ViewModel・テーマ・ナビゲーション
├── domain/    # ドメインモデル・ユースケース（Android 非依存）
└── data/      # リポジトリ・DataSource・Room・DataStore
```

**依存の向きは ui → domain ← data の一方向。**

- `domain` は Android SDK に依存しない（実機なしでユニットテストできる状態を保つ）
- `data` のエンティティ・DTO を `ui` へ直接渡さない。境界で `domain` のモデルへ変換する
