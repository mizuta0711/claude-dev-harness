# 設計書同期トラッキング

コミットごとに設計書（`docs/設計書/` 配下）の同期状態を記録する台帳。
`/harness-core:update-docs` 実行時に自動追記する。
プッシュ前チェックは `grep` でコミットハッシュの存在を確認するのみ（内容は見ない）。

## ルール

- `/harness-core:update-docs` 実行時: 対象コミットのハッシュ・日付・同期先・判定を追記する
- 設計書の更新が不要なコミット（軽微なバグ修正・設定変更等）も **`更新不要（理由）` として記録する** — 無記録は許さない
- プッシュ前チェック: `git log --format=%h @{upstream}..HEAD` の全ハッシュがこのファイルに
  存在するかを確認する（`/harness-core:pre-push-check`）
- 同期先に書く設計書名は `.claude/harness.config.json` の `designDocs.docs[].file` に対応する

## 同期記録

| コミット | 日付 | 同期先 | 判定 |
|---------|------|--------|------|
| (テンプレート) | — | （全設計書） | テンプレート初期化 |
