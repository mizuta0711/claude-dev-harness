# 残作業（backlog）

> **この文書が残作業の唯一の正である。** 他の文書に残作業表を作らない。

| 項目 | 内容 |
|------|------|
| 進捗の書き方 | **完了したものは行ごと消す。** 「✅完了」を積み上げない（履歴は git が持つ） |
| 進捗の在り処 | **ここには書かない。** 各機能の進捗は**その設計書のメタ情報**と**置き場**（`docs/features/planned/` か直下か `completed/`）が正 |
